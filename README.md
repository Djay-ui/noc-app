# Teleglobal NOC Operations Engine

An enterprise Network Operations Center (NOC) dashboard for managing network circuits, ticket dispatches, fiber inventories, and system notifications.

---

## 🛠️ Tech Stack
* **Backend:** FastAPI / Python 3.10+
* **Frontend:** HTML5, CSS3, JavaScript (Jinja2 Templates, FontAwesome)
* **Database:** SQLite / PostgreSQL
* **Mail & Alerts:** SMTP Integration, PRTG Live Stream Integration

---
